# 项目约定

每个新角色记录一次，后续局部编辑继承。新用户明确约定优先于示例。

## 记录字段

- 身份与版本：原设定图、整角色基准、各模块已确认参考。
- 模块归属：包含与不包含内容；兽耳、发夹、围巾、手、尾巴分别归属。
- 姿态：T-pose或A-pose，脚尖方向、双腿间距、手掌方向。
- 方向：正后左右或用户指定组合；左右按角色自身定义。
- 比例与标记：头身比例、冠顶、刘海末端、眼线、肩、袖口、裙摆、袜口、膝部、鞋底的相对位置。
- 头发简化：总轮廓、长度、流向、沟槽深浅和末端厚度，不固定所有角色的发块数量。
- 头发切分：采用前后180°时为头部中心竖直冠状平面；用户其他规则优先。
- 接口参考：刘海与后发共用头壳；头部与头发空腔；短颈与围巾领口；裙摆与大腿；手腕与袖口。
- 外观：肤色、发色、衣服配色、眼部高光及不对称装饰。
- 交付：画幅、背景、分辨率、原生与导出尺寸、版本命名、确认状态。

## 本次角色示例

五个模块为刘海、后发、衣服、脸部、腿部与袜子与鞋子；衣服后来扩展为衣服与手部。兽耳归后发，鱼形发夹归角色左侧刘海，围巾唯一垂挂端归角色左前胸。T-pose，双掌向下，双腿自然分开，脚尖平行向前。头发深蓝灰、毛衣蓝灰、围巾蓝格、裙袜深蓝、鞋棕色。

刘海与后发以头部中心竖直冠状平面分隔；采用浅沟槽、宽厚体块、圆钝发尾。脸部以保留高光的V3为最新参考，衣服与手部为最新服装参考。背景为浅灰#F2F2F2。原图有尾巴，但当前五模块尚未分配，不把它认定为已完成部件。

## 文件记录

可在项目工作区保存character-spec.md和asset-manifest.json。清单至少包含模块、版本、视角、路径、原生像素、导出像素、参考图、确认状态和接口说明。文件名可用part-front-v01.png、part-back-v01.png、part-left-v01.png、part-right-v01.png；它们是命名建议，不是固定目录要求。

## 模型阶段记录字段（阶段二、三）

这些内容写进项目的 `config.yaml`（流水线）和 `ue_config.json`（UE）。不能放进配置的约定写在 character-spec.md。

- 模型来源：生成器与版本，blend 路径（只读），对象名与模块的对应关系。
- 坐标与单位：是否面朝 −Y、Z 向上、米制、脚底在 z≈0；身高。
- 原始数据：原 UV 层名（`source_uv`）；原贴图的来源（副本对象后缀，或对象自身材质）；有没有法线、粗糙度等额外贴图（不随 UV 迁移）。
- 骨架：名字、骨骼数、命名习惯（UE 小白人、Mixamo、VRM 等）；有没有手指骨骼和次级骨骼（头发、裙子、耳朵）。
- 图集：
  - 贴图尺寸、各对象的显示名；
  - 每个对象用 `generic` 还是专用分区规则；
  - 打包组的顺序与合并，`prio` 的例外。
- 贴图清理：
  - 送了哪些裁块，没送哪些、为什么（脸和眼睛默认不送）；
  - 提示词文件、`detail_override`；
  - 采纳和退回的结果。
- 定点修正：用户指出的问题（原话）对应到哪条 `touchup`（对象、部位、操作、参数），修正后的验证图。
- 交付：`package_dir`、导出文件名，残留问题清单。
- UE：
  - 项目路径与引擎版本；内容根目录；有没有第三人称模板内容；
  - 胶囊半高与半径、`mesh_yaw`、双面部件、只对齐的骨骼；
  - 构建和测试报告的位置。

## 本次角色示例（模型阶段）

- **模型**：Tripo 生成、在 Blender 里绑好的五个模块。`CHR_Head`、`CHR_Body`、`CHR_Legs`、`CHR_FrontHair`、`CHR_BackHair_Ears` 各一张 4K 图集。
  - 原 UV 层 `UV_orig`；原贴图在 `<对象>_NormalReference` 副本上。
  - 骨架 `SK_SourceParts`，64 根骨骼，UE 小白人式命名，另有头发、裙摆、耳朵、围巾骨骼，没有手指骨骼。身高 1.70 m。
- **分区与排布**：用了专用分区规则（`legs`、`body`、`head`、`front_hair`、`back_hair`）。原始 13087 个岛重排成 186 块。
- **贴图清理**：用 ChatGPT 清理了衣服、腿鞋、头发共 21 块，脸和眼睛未送。格纹围巾和领口两块关掉了细节回叠。
- **定点修正**：
  - 袜子上的灰色竖条纹是 Tripo 烘焙的阴影，已去掉；
  - 腿部上端的白色其实是大腿皮肤，改成了脖子的肤色；
  - 腿后接缝处的袜口线已对齐，残留亮点已清掉。
- **UE**：GakumasToon（UE 5.7），内容放在 `/Game/SourceParts_Playable`。胶囊 86/30。衣服和头发双面。只把手臂从 T-pose 对齐到 A-pose，脚部 IK 改为直通。
