# 模块化角色提示词库

使用前将【视角】替换为下面的方向语句，并附上提示词中说明角色的参考图片。一次调用生成一张图；四视图交付四个独立文件。此库中的配色与服装是本次角色示例，换角色时先替换身份描述，再保留几何与一致性约束。

## 方向语句

- 正视：Front orthographic view，观察物体前方，水平光轴。
- 后视：Back orthographic view，摄像机绕同一物体转180°，物体姿态不变。
- 左视：Anatomical left orthographic view，严格90°左侧，角色前方指向画面左。
- 右视：Anatomical right orthographic view，严格90°右侧，角色前方指向画面右。
- 俯视只在用户要求时生成，Top orthographic view；不替代当前约定的后视。


## 局部修复提示词

### 头发过碎

```text
只简化当前头发的分束结构。保持原轮廓、长度、流向、颜色、切面和接口不变；将细发丝合并为少量根部连通的宽厚体块，使用浅沟槽表达分界，将尖细发尾改为圆钝厚实末端。不要增加发束、改变刘海长度或重新设计发型。
```

### 眼部阴影与高光

```text
只取消眼白上缘灰影、眼睑投影、眼窝环境遮蔽和眼周暗缝，使眼白均匀暖白、眼缘贴合脸部。保留原棕色虹膜、瞳孔、眼距、表情以及虹膜内的小白色高光。不要删除高光、抬高眼片或改变脸型。
```

### 左右装饰错误

```text
只纠正不对称装饰的归属。鱼形发夹始终位于角色左侧；本图若为右视，则按真实遮挡隐藏它并恢复下方连续发面，不复制到右侧。围巾垂挂端始终位于左前胸，不能因镜像复制到另一侧。其余几何、材质和纵向位置保持不变。
```

### 严格侧视遮挡

```text
只校正侧视中的遮挡。保持两腿或双臂原来的平行站姿与T-pose，在严格90°正交侧视中，让远侧相同部件按真实投影被近侧遮挡；移除人为错开的远侧鞋或手。不要改变站姿、模块长度、袜口、袖口、鞋底标高和镜头俯仰。
```

### 刘海与后发接口

```text
只纠正前后发接口。以后发已确认的空腔、冠顶、壁厚和太阳穴端点为基准，让刘海后缘落在同一个头部中心竖直冠状平面。侧视切边为竖直线，保留前半头壳与原刘海长度；移除额外后脑壳、接缝台阶和新增连接件。不要重画已确认后发。
```
